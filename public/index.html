方法说明 / 可靠性

转换在浏览器内由 官方 RDKit（编译为 WebAssembly） 完成，算法与 Python 版 rdkit 完全一致：

① 解析 molfile（V2000/V3000）；② AddHs 补齐氢；③ EmbedMolecule 用 ETKDGv3（实验扭转修正的距离几何）生成三维坐标；④ 用 MMFF94 或 UFF 力场做几何优化。无 MMFF 参数时自动回退 UFF。

本 WASM 由 RDKit 源码 Code/MinimalLib 自行编译，并新增 3D 接口绑定。化学上与 RDKit 原生实现一致，非近似启发式。
